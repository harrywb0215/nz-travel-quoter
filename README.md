# NZ Travel Quoter - 新西兰定制游行程与报价管理系统

专为新西兰地接导游、定制游工作室打造的现代化、高颜值行程解析与高保真 Excel 报价单生成工作台。

## 🌟 核心特性
- **客户 Excel 智能导入解析**：拖拽上传客户行程单，自动识别天数、城市路线、游玩活动与“不用车”状态。
- **100% 格式对齐输出**：严格按照标准模板（双黄色高亮标题、红字标注、虚线/实线边框、合并单元格）导出 Excel 与高清 PDF。
- **业务参数与价格维护中心**：
  - 南岛 / 北岛司导餐补（$50~$75 / $40~$60）
  - 异地住宿补贴、工时上限（10h）与超时单价（NZD 150/h）
  - 车型库（7座 Alphard、16座奔驰+拖斗等）日租与节日附加费管理
  - 新西兰景点门票单价库随时修改与新增
  - 配置本地永久保存，支持一键备份与导出为 JSON 文件
- **草稿箱与历史记录**：随时保存客户报价单草稿并调出复用。

## 🚀 本地开发与构建
